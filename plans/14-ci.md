# 14 — CI pipeline

## Goal

GitHub Actions (or equivalent) runs build, tests, and plugin validation on every push/PR.

## Approach

1. Add `.github/workflows/ci.yml`:
   - Node 22
   - `cd mcp && npm ci && npm run build && npm test`
   - `node scripts/validate-template.mjs` from repo root
2. Cache npm dependencies.
3. Depends on [12-integration-tests](12-integration-tests.md) for a real `npm test`; until then run `npm run smoke` + `build` + validate.

## Acceptance

- PR checks fail on TypeScript errors, smoke tool-list drift, or invalid skill frontmatter.
